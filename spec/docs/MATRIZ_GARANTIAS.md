# Matriz de garantías y limitaciones (v1.1)

Cada fila dice qué se quiere garantizar, con qué mecanismo, bajo qué condiciones, de qué hardware depende, qué riesgo queda y con qué prueba se acepta. La tabla se genera desde `docs/guarantees.json`.

| Clase | Significado |
| --- | --- |
| Software | Demostrable con software y pruebas automatizadas contra simuladores y SQL Server real |
| Integración física | Requiere equipos y su integración con el PLC; el software solo puede reportar |
| Rendimiento | Objetivo medible; no es una garantía hasta que un benchmark lo confirme |
| Supuesto OT | Depende de una decisión de planta pendiente (`docs/DECISIONES_ABIERTAS_OT.md`) |
